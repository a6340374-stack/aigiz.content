# Айгиз | Контент-лаборатория

Статический веб-калькулятор для проверки контент-гипотез. 18 стартовых гипотез, по 4 редактируемые темы для каждой. Ввод результатов Reels, автоматический расчёт долей сохранений, переходов и подписок, экспорт JSON/CSV, импорт резервной копии.

## Использование

Откройте `index.html` в браузере. Данные сохраняются в localStorage **только этого браузера**. Для резервного копирования используйте «Экспорт JSON».

## Публикация на GitHub Pages

1. Создайте **публичный** репозиторий на GitHub.
2. Загрузите `index.html` и `README.md` в корень ветки `main`.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите `main` и `/ (root)`.
4. После публикации сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

Данные посетителей не синхронизируются между устройствами и не отправляются на сервер.
